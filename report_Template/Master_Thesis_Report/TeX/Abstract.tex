\chapter*{Abstract}

This thesis introduces a proof-of-concept FPGA Verification Platform designed to enhance and accelerate the verification and validation of FPGA modules within servo drive control boards at Schneider Electric. Existing verification processes rely on manual procedures, static tests, and external hardware such as motors, resulting in extended development cycles, limited test coverage, and difficulties observing timing-critical FPGA modules. To overcome these challenges, a dedicated platform was developed utilizing a Zynq UltraScale+ MPSoC-based Enclustra Mercury XU5 System-on-Module and a DAC80508 evaluation board. This platform enables automated, repeatable, and independent testing of key FPGA modules, including the Current Sense SPI interface, PWM generator, and Overcurrent (OVC) detection module, as well as evaluation of module responses on actual hardware.

The platform supports both static and dynamic testing, utilizes software control through AXI interfaces, and integrates on-chip signal analysis for real-time verification. Experimental results demonstrate that the platform accurately reproduces reference signals, reliably detects current thresholds, and consistently measures PWM performance under diverse conditions. These findings indicate that the platform reduces manual intervention, facilitates fault detection, and enables comprehensive validation prior to release without the need for external hardware. This work establishes a foundation for the future development of a fully automated continuous integration and continuous deployment (CI/CD) verification platform for servo-drive FPGA designs.
